Connect Google to get started

Authorize read-only access to the playlists your account owns. This tool cannot change your library.

  1. In Google Cloud, enable the YouTube Data API v3 and create an OAuth client with application type Desktop app.
  2. Save the downloaded client JSON locally as .local\client-secret.json, or set GOOGLE_CLIENT_SECRET_FILE to its path.
  3. After saving or replacing the file, use Recheck connection below. If you changed the configured file path, restart the local server with npm start first. See README.md for complete setup and test-user instructions.

Keep the client secret on your machine. There is no secret-entry field in this interface.

What the backup preserves

JSON is the authoritative archive. It preserves playlist metadata, ordered entries, provider details, and availability information returned by the API.

CSV is a readable table. M3U8 contains available source links, not downloaded music. Unavailable entries and missing details are retained or reported where the API exposes them; no format can restore information the API withholds.

Each run creates a new local backup; earlier exports are kept until their 30-day expiry. Partial results and warnings remain visible in backup history until then.

API metadata is subject to Google retention and refresh policies; see README.md before keeping long-term archives.
