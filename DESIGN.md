# Design System

## Direction
Soundiiz Local Archive uses an archival workbench metaphor: a dependable, paper-like surface with ruled records and compact controls rather than a conventional tile dashboard. The interface prioritizes playlist selection, backup state, and file retrieval.

## Color
- Paper `#f4f1e8`: page field
- Surface `#fffdf7`: active workspace
- Ink `#142238`: structure, primary actions, text
- Muted `#5d6875`: supporting information
- Rule `#c9c4b8`: data separation
- Amber `#e9a522`: focus and progress
- Green `#247151`: connected state
- Red `#a33b32`: actionable errors

## Typography
Use Avenir when available, followed by Segoe UI and Arial. Headings are compact and tightly tracked; labels and operational metadata remain restrained and highly legible.

## Components and Layout
Controls are squared with consistent 2px corners. Content groups use rules and shared surfaces instead of repeated floating cards. Desktop uses a dominant playlist catalog beside a fixed-width control station; mobile stacks the two without changing task order. Keyboard focus is always a visible amber outline.

## Motion
Motion communicates only state: playlist hover and native progress updates. Reduced-motion preferences disable transitions and loading animation.
